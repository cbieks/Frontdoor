# Frontdoor marketing site, design context

Register: **brand**. Brand: **Frontdoor's own** (to be defined). Goal: an
over-the-top, award-winning-agency-grade site that converts prospects and proves
Frontdoor can build beautiful sites. This is the showcase, so it must itself pass
the anti-slop bar.

`PRODUCT.md` and `DESIGN.md` for this surface are generated by `/impeccable teach`
(then `/impeccable shape`) in a session where
`IMPECCABLE_CONTEXT_DIR=docs/design/website`. Defining Frontdoor's own brand
identity (palette, type, voice, logo) is the first step, and the dashboard will
share that foundation.
